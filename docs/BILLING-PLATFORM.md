# CloudOn Billing — δική μας πλατφόρμα στη θέση του WHMCS

**Στόχος:** να αναλάβει σταδιακά ό,τι κάνει σήμερα το WHMCS για εμάς, ώστε στο τέλος η
άδεια του WHMCS να **ακυρωθεί νόμιμα** (όχι να παρακαμφθεί) χωρίς καμία διακοπή.
Το WHMCS μένει ζωντανό, με άδεια και ενημερώσεις ασφαλείας, ώσπου να περάσουμε.

## Τι χρησιμοποιούμε από το WHMCS (μέτρηση 6/10/2026)

| | πλήθος |
|---|---|
| Ενεργοί πελάτες / σύνολο λογαριασμών | 26 / 244 |
| Ενεργές υπηρεσίες / σύνολο | 229 / 1.128 |
| Domains | 0 |
| Τιμολόγια ανά μήνα / σύνολο | ~58 / 3.599 |
| Κινήσεις πληρωμών ανά μήνα / σύνολο | ~68 / 3.460 |
| Tickets ανά μήνα | ~19 |
| Πύλες πληρωμής (6 μήνες) | τράπεζα 218 · PayPal 57 · Viva 5 |
| Αυτοματισμός υπηρεσιών | 203 χωρίς module · 16 Hetzner (δικό μας) · 6 Plesk · 4 MarketConnect |

Τα **νόμιμα παραστατικά** (ΑΑΔΕ/myDATA) εκδίδονται από το SoftOne — το WHMCS δεν διαβιβάζει.
Άρα το δικό μας σύστημα χρεώσεων δεν αναλαμβάνει φορολογική έκδοση· κρατά λογαριασμό πελάτη,
προτιμολόγια/ειδοποιήσεις πληρωμής, πληρωμές και αυτοματισμούς.

## Αρχιτεκτονική

- **Φάκελος `billing/`** — ανεξάρτητη βιβλιοθήκη PHP με **δικό της PDO** (όχι Capsule/`init.php` του WHMCS),
  ώστε να μπορεί να τρέξει χωρίς το WHMCS. Δεν είναι προσβάσιμος από τον browser (`.htaccess` deny) —
  τα εργαλεία είναι μόνο γραμμής εντολών μέχρι να μπει UI.
- **Πίνακες `cob_*`** στην ίδια βάση προσωρινά (προσθετικοί — το WHMCS τους αγνοεί). Μεταφορά σε
  ξεχωριστή βάση στη Φάση 5.
- Κάθε εγγραφή κρατά `whmcs_id` → η αντιγραφή είναι **επαναλήψιμη** (upsert) και ελέγξιμη 1-προς-1.
- Ποσά πάντα `DECIMAL(12,2)`, ποτέ float.
- Το UI διαχείρισης ανήκει στο admin panel (κανόνας διαχωρισμού: billing/υπηρεσίες ≠ Project Manager).

## Φάσεις

| Φάση | Τι | Κριτήριο ολοκλήρωσης |
|---|---|---|
| **0** | Σχέδιο · πίνακες `cob_*` · αντιγραφή WHMCS → cob · έλεγχος συμφωνίας | `cob verify` = 0 διαφορές σε πλήθη και ποσά |
| 1 | Χρεώσεις: επαναλαμβανόμενα τιμολόγια, πληρωμές (τράπεζα/PayPal/Viva), πίστωση, PDF/email | 1 μήνας παράλληλα: ίδια τιμολόγια με το WHMCS |
| 2 | Αυτοματισμοί: υπενθυμίσεις, αναστολές/επανενεργοποιήσεις, παράδοση VM (Hetzner, Plesk) | ίδιες ενέργειες με το cron του WHMCS για 2 εβδομάδες |
| 3 | Portal πελάτη: είσοδος, υπηρεσίες, τιμολόγια, πληρωμή, παραγγελίες | πελάτες δοκιμής χωρίς WHMCS |
| 4 | Tickets μέσω email (εισερχόμενα/απαντήσεις) | όλα τα κανάλια ticket χωρίς WHMCS |
| 5 | Τελική μεταφορά, WHMCS μόνο-ανάγνωση, ακύρωση άδειας | καμία ενέργεια δεν περνά από WHMCS |

**MarketConnect** (4 υπηρεσίες) είναι μεταπωλητικό πρόγραμμα του WHMCS — χρειάζεται άλλος πάροχος ή
χειροκίνητη διαχείριση πριν τη Φάση 5.

## Φάση 0 — τι υπάρχει

```
billing/lib/Db.php           PDO από configuration.php (μέχρι να έχει δικό του .env)
billing/lib/Schema.php       οι πίνακες cob_* (επαναλήψιμο, προσθετικό)
billing/lib/WhmcsImport.php  αντιγραφή WHMCS → cob (upsert ανά whmcs_id, μόνο ΑΝΑΓΝΩΣΗ από WHMCS)
billing/lib/Verify.php       έλεγχος συμφωνίας: πλήθη, ποσά ανά κατάσταση, υπόλοιπα ανά πελάτη
billing/bin/cob              migrate | import [--dry] | verify
```

```
php billing/bin/cob migrate      # φτιάχνει/συμπληρώνει τους πίνακες
php billing/bin/cob import       # αντιγράφει (ξανά και ξανά, χωρίς διπλά)
php billing/bin/cob verify       # αναφορά διαφορών — πρέπει να βγαίνει 0
```

| WHMCS | cob |
|---|---|
| tblclients (+ ΑΦΜ cf#1, ΔΟΥ cf#82) | cob_clients |
| tblproducts + tblproductgroups + tblpricing | cob_products + cob_product_prices |
| tblhosting (+ config options) | cob_services |
| tblhostingaddons | cob_services (kind=addon) |
| tblinvoices / tblinvoiceitems | cob_invoices / cob_invoice_items |
| tblaccounts | cob_payments |
| tblcredit | cob_credit_log |

## Τρεις εφαρμογές, ένας πυρήνας (απόφαση 6/10/2026 — «admin, my, project»)

| Εφαρμογή | Για ποιον | Σήμερα | Στο νέο σύστημα |
|---|---|---|---|
| **admin** | διαχείριση (λογιστήριο, τεχνικοί) | WHMCS `/cloudonadminpanel` + δικά μας addons | πελάτες & στοιχεία, προϊόντα/τιμές, υπηρεσίες & VM, τιμολόγια, πληρωμές, αναστολές, αναφορές εσόδων |
| **my** | πελάτες | WHMCS client area (`my.cloudon.gr`) | είσοδος, οι υπηρεσίες μου, τιμολόγια & πληρωμή, παραγγελία, tickets, προφίλ/ΑΦΜ |
| **project** | ομάδα | `/project/` (δικό μας) | μένει ως έχει — PM/CRM/tickets/ομάδα· διαβάζει από τον κοινό πυρήνα αντί για τους πίνακες του WHMCS |

**Κοινός πυρήνας (`billing/lib` → `core/`)**: ΜΙΑ υλοποίηση των κανόνων (πελάτης, υπηρεσία, τιμολόγιο,
πληρωμή, αναστολή) — καμία εφαρμογή δεν γράφει απευθείας σε πίνακες. Το admin και το my είναι
οθόνες πάνω στον πυρήνα· το project τον καλεί όπου σήμερα αγγίζει tbl* του WHMCS.

**Ταυτοποίηση** (σήμερα την κάνει το WHMCS): δύο «κόσμοι» — *προσωπικό* (από tbladmins, με τα υπάρχοντα
δικαιώματα ρόλων του project) και *πελάτες* (από tblclients). Οι κωδικοί του WHMCS είναι bcrypt/
`password_hash`, άρα μεταφέρονται χωρίς να ζητηθεί από κανέναν νέος κωδικός (επιβεβαιώνεται στη Φάση 1).

**Σειρά**: πρώτα ο πυρήνας + admin (Φάσεις 1–2, όσο το WHMCS κάνει ακόμη τις πληρωμές), μετά my (Φάση 3),
και το project περνά στον πυρήνα σταδιακά, οθόνη-οθόνη. Το project ΔΕΝ ξαναγράφεται.

**Ανοιχτά για απόφαση**: διευθύνσεις (π.χ. `admin.cloudon.gr` · `my.cloudon.gr` για πελάτες · `/project/`),
και αν το admin θα είναι ενότητα μέσα στο project (ένα login για την ομάδα) ή ξεχωριστή εφαρμογή.
