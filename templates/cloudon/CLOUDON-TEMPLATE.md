# Πρότυπο πελάτη `cloudon`

**Αυτό το πρότυπο ανήκει αποκλειστικά σε εμάς. Κανένας εξωτερικός δεν γράφει επάνω του.**

## Τι είναι

Fork του εμπορικού προτύπου **horn**, στις 30/07/2026, από την έκδοση που έτρεχε
τότε στην παραγωγή — μαζί με όλες τις δικές μας προσαρμογές.

Δημιουργήθηκε γιατί το `horn` είναι προϊόν τρίτου: μια ενημέρωσή του θα έσβηνε
τις 23 τροποποιήσεις μας χωρίς προειδοποίηση.

## Τι άλλαξε σε σχέση με το horn

Μόνο διαδρομές, καμία λειτουργική αλλαγή:

- `templates/horn/` → `templates/cloudon/`
- `orderforms/horn/` → `orderforms/cloudon/`
- `carttpl=horn`, `systpl=horn` → `cloudon`

**Δεν** αγγίχτηκαν τα `icohorn` (φάκελος εικονιδίων) και `bullhorn` (εικονίδιο
FontAwesome) — μοιάζουν με το όνομα του προτύπου αλλά δεν έχουν σχέση.

Συνολικά 17 αρχεία, ~40 αναφορές.

## Πώς συνεχίζουμε να επωφελούμαστε από το horn

Το `templates/horn/` παραμένει εγκατεστημένο και **ανέπαφο**, ως σημείο αναφοράς.
Όταν βγει νέα έκδοση horn:

1. Κράτα αντίγραφο: `cp -a templates/horn /root/horn-old-$(date +%F)`
2. Εγκατέστησε τη νέα έκδοση **μόνο** στο `templates/horn/` (είναι ανενεργό, ακίνδυνο)
3. `diff -ru /root/horn-old-ΗΜΕΡΟΜΗΝΙΑ templates/horn` → τι άλλαξε ο κατασκευαστής
4. Μετάφερε χειροκίνητα στο `cloudon/` μόνο ό,τι αξίζει

Έτσι βλέπεις τις βελτιώσεις του κατασκευαστή χωρίς να ρισκάρεις τις δικές σου.

## Δοκιμή χωρίς αλλαγή του ζωντανού

```
https://my.cloudon.gr/index.php?systpl=cloudon&carttpl=cloudon
```

## Ενεργοποίηση

Setup → General Settings → Template = **cloudon**, και Ordering → Order Form
Template = **cloudon**. Ή απευθείας στη βάση, `tblconfiguration`:
`Template` και `OrderFormTemplate`.

Μετά: `rm -f tpl_cache_k7m2/*.php`

## Επιστροφή πίσω

Αν κάτι πάει στραβά, βάλε ξανά `horn` στις δύο ρυθμίσεις. Το horn παραμένει
πλήρες και λειτουργικό.
